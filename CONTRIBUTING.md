# Contributing to Qarta Online

1. **Ticket first.** Every change needs a ticket before you branch or open a PR.
2. **Branch name.** Use the item ID, a slash, and a short kebab-case slug from the title (e.g. `ISS-10/login-redirect`, `US-12/account-profile`).
3. **One PR per item.** Open a single pull request for that item and fill in the org [pull request template](./PULL_REQUEST_TEMPLATE.md).
4. **Review before merge.** Nothing merges to `main` without review from @estzep.
