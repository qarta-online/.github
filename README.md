# Qarta Online — org GitHub defaults

This repository (`qarta-online/.github`) holds **organization-wide GitHub defaults** for Qarta Online: the public org profile README, community health files, the default pull request template, contribution rules, and Actions workflow starters.

It is not application source. App code lives in `portal`, `web`, `server`, `toolkit`, `workspace`, and `planner`.

Clone locally without the leading dot so the folder is not hidden:

```bash
git clone https://github.com/qarta-online/.github github
```

Contribution rules: [`CONTRIBUTING.md`](./CONTRIBUTING.md).
